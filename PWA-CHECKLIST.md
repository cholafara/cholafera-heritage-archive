# PWA & Google Play Store Deployment Checklist

Since this site is now built as a Progressive Web App (PWA) with a valid `manifest.json` and a Service Worker (`sw.js`), you can package it into a native Android application using Trusted Web Activity (TWA) via Bubblewrap. 

Follow these steps once you have finalized your data entry (catalog JSONs) and imported images.

## Phase 1: Preparation
1. **Data Ready:** Ensure all Excel catalogs are filled and imported, and images are optimized.
2. **Deploy to Hosting:** Make sure your Netlify/Vercel/GitHub Pages deployment is live, serving over HTTPS.
3. **Verify PWA:** Visit your site on Google Chrome (desktop or mobile) and check if the "Install App" or "Add to Home Screen" prompt appears.

## Phase 2: Packaging the App (Bubblewrap)
You can build the Android APK/AAB bundle locally using Bubblewrap (CLI).

1. Install Node.js if you haven't already.
2. Run the following command to install Bubblewrap globally:
   ```bash
   npm install -g @GoogleChromeLabs/bubblewrap
   ```
3. Initialize the Android project (run this in a new directory outside your repo or in a dedicated `android-app` folder):
   ```bash
   bubblewrap init --manifest="https://cholafera-heritage-archive.netlify.app/manifest.json"
   ```
   *Note: Replace the URL with your actual live domain.*
4. Follow the prompt instructions (it will ask you to confirm details from your manifest and set up signing keys).
5. Build the APK/AAB:
   ```bash
   bubblewrap build
   ```
   This will generate an `app-release-bundle.aab` file, which is required for the Play Store.

## Phase 3: Google Play Console
1. **Create Developer Account:** Go to [Google Play Console](https://play.google.com/console/about/) and sign up.
2. **Pay the Fee:** There is a **$25 one-time registration fee**.
3. **Create App:** Click "Create App", enter the app name ("Cholafera Heritage Archive"), language, and confirm it's a free app.
4. **App Details:** Fill out the Store Listing (short description, full description, screenshots, and the 512x512 logo we created).
5. **Upload AAB:** Go to "Production" -> "Create new release" and upload the `app-release-bundle.aab` generated by Bubblewrap.
6. **Submit for Review:** Once all mandatory fields (Privacy Policy, Data Safety, Content Rating) are filled, submit the app for Google's review.

*It usually takes 3 to 7 days for the app to go live on the Play Store after the first submission.*
